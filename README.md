# Retail-Business-Intelligence-Customer-Analytics-

Retail Business Intelligence & Customer Analytics

Project Overview

This project focuses on analysing online retail transaction data to identify sales performance, customer purchasing behaviour, product performance, and business trends.

Tools & Technologies

- Microsoft Excel
- Python (Pandas)
- Power BI
- Data Cleaning and Data Visualization

Dataset Information

- Dataset: Online Retail Dataset
- Original Records: 541,909 rows
- Data includes invoice numbers, product details, quantities, prices, customer IDs, dates, and countries.

Project Activities

Excel

- Data cleaning and preparation
- Data quality analysis
- Pivot table analysis
- KPI calculations and dashboard creation

Python

- Data cleaning using Pandas
- Missing value and duplicate analysis
- Sales and customer analysis
- Data visualization

Power BI

- Interactive business dashboard
- Executive overview
- Product performance analysis
- Customer intelligence
- Market and transaction analysis

Key Business Metrics

- Total Revenue
- Total Orders
- Total Customers
- Total Quantity Sold
- Average Order Value (AOV)
- Repeat and One-Time Customers
- Cancellation Rate

Project Screenshots

Dashboard screenshots are available in this repository.

Conclusion

This project demonstrates practical skills in data cleaning, exploratory data analysis, business intelligence, KPI reporting, and data visualization using Excel, Python, and Power BI.
